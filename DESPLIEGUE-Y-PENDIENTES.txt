2. VARIABLES DE ENTORNO (.env / .env.example)
--------------------------------------------------------------------------------

- NEXT_PUBLIC_SITE_URL
    URL base para canonical, sitemap, robots y Open Graph.
    - Por defecto: https://www.doctorbolao.com
    - GitHub Pages: https://TU-USUARIO.github.io/TU-REPO
    El basePath se deriva automáticamente de esta variable.

- CONTACT_TO (opcional)
    Destinatario del formulario. Por defecto consulta@doctorbolao.com

- CONTACT_MAIL_MODE=log (solo desarrollo)
    Valida y registra en consola, sin enviar correo real.

- CONTACT_WEBHOOK_URL / CONTACT_WEBHOOK_TOKEN (opcional, envío real)
    Webhook (Zapier, Make, worker propio...) que recibe el JSON del formulario
    y reenvía el correo. Sin esto, el envío responde "no configurado".
